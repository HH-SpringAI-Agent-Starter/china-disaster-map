# 中国自然灾害分布图 · 城市级（可按年月检索）

基于自然资源部标准地图（DataV GeoAtlas）绘制的中国**地级市**自然灾害分级填色图，
覆盖 **1926–2026 百年** 时空分布，支持 **按年份 / 月份 / 灾害类型 / 关键词检索**，
并在地图上联动高亮命中城市。

> ⚠️ **重要说明**：底图含南海诸岛及断续线，依国家标准示意呈现；色阶为相对灾害强度示意，**非精确统计**。

## 二、功能

- **双栏地图**：左为 2026 年当前态势，右为 1926–2026 百年累计（频次＋伤亡）分级填色。
- **年月检索**：顶部下拉框选年份 / 月份 / 灾害类型，输入关键词，下方时间轴即时过滤。
- **地图联动**：筛选后自动高亮命中的地级市，其余置灰（`.hit` / `.dim` 类切换）。
- **安全指数面板**：给出「最安全 / 最适合发展」城市梯队（**仅衡量自然灾害暴露度**）。
- **数据自动更新**：页面加载时优先拉取在线 `disaster_data.json`；离线或拉取失败则回退内置数据。

## 三、数据说明（字段备注）

数据全部集中在 **`disaster_data.json`**（唯一数据源），结构如下：

```json
{
  "meta": {
    "title": "…", "updated": "2026-09", "note": "…", "disclaimer": "…",
    "types": ["地震","洪涝","干旱","台风","火灾","雪灾","泥石流","疫情"],
    "typeColor": { "地震": "#…", "…": "…" },
    "levelName": { "1": "较轻", "2": "中等", "3": "较重", "4": "重大" }
  },
  "events": [
    { "year": 2026, "month": 5, "type": "地震", "region": "广西",
      "city": "柳州", "detail": "5月18日一天内两次5.2级地震", "level": 4, "source": "中国地震台网" }
  ]
}
```

`events` 每条事件字段含义：

| 字段 | 必填 | 说明 |
|------|------|------|
| `year` | 是 | 公历年份（整数，如 1926 / 2026） |
| `month` | 是 | 月份 1–12；当前数据集**每条事件均已填写月份**，年份级 / 年度预报类条目取该灾种典型或峰值月份（非具体日期） |
| `type` | 是 | 灾害类型，须取自 `meta.types` 之一 |
| `region` | 是 | 省级行政区名（如「广西」「广东」） |
| `city` | 否 | **地级市短名**（如「柳州」「广州」）；也可填县级市 / 自治州 / 直辖市整市，页面会经 `city_alias.json` 回退解析到地图节点再高亮（详见下文「地名回退」）；流域 / 省级层面事件留空 `""` |
| `detail` | 是 | 事件描述（一句话） |
| `level` | 是 | 灾情等级 1=较轻 / 2=中等 / 3=较重 / 4=重大 |
| `source` | 是 | 数据出处（年鉴 / 台网 / 用户年表等） |

> 目前内置 **152 条**事件（1926–2026 全部事件均已补齐年份与月份，能落到地级市的均已标注 `city` 以联动高亮），覆盖 2026 重点城市与百年年表；其余城市继承省级基础等级。

**地名回退（`city_alias.json`，由 `build_alias.py` 生成）**

事件里的 `city` 未必等于地图节点名——地图节点是地级行政区（自治州用民族全称，如「甘孜藏族」「玉树藏族」），直辖市则按市辖区拆分。为避免这些事件在地图上不亮，构建时生成回退别名表，页面按以下顺序解析：

1. 节点名精确命中（如「成都」「通辽」）→ 直接高亮
2. 县 / 县级市 → 回退到所属地级节点（如「都江堰」→「成都」、「汶川」→「阿坝藏族羌族」、「舟曲」→「甘南藏族」）
3. 自治州短名 → 全称节点（如「玉树」→「玉树藏族」、「巴音郭楞」→「巴音郭楞蒙古」）
4. 直辖市整市 → 展开为该市全部市辖区（如「北京」→ 16 区、「重庆」→ 38 区）
5. 台湾各县市 → 台湾省节点

当前数据集中 **103 个城市全部可解析到地图节点（命中率 100%）**。新增事件时若引入新地名，重跑 `build_alias.py` + `gen_html_city.py` 即可纳入。

`city_data.json` 为各城市分级与安全指数（由 `gen_city_map.py` 生成），字段含 `name`、百年等级、2026 等级、安全指数、梯队（S/A/B/C/D）。

## 四、关键备注

1. **标准地图合规**：底图不手绘，全部取自 DataV GeoAtlas（基于自然资源部标准地图），含南海诸岛断续线。
2. **安全指数算法**：`安全指数 = 100 − (0.6×百年等级×25 + 0.4×2026等级×25 + 惩罚)`，惩罚含地震带 +6 / 七大流域中下游 +5 / 台风沿海 +4；直辖市、港澳按整市聚合。
3. **安全指数用途边界**：仅衡量自然灾害暴露度，**不含经济、人口、基础设施与防灾能力**，不作选址或投资决策依据。
4. **联动高亮前提**：检索要命中地图，事件的 `city` 必须与该城市在地图上的 `data-name` 完全一致（用地级市短名）。
5. **自动更新机制**：页面 `fetch` 仓库 `main` 分支的 `disaster_data.json`；若网络不可达或返回非 200，则使用内嵌 `<script id="fallback">` 的快照数据，保证离线可用。
6. **数据校正记录**：已订正原材料中「1950 年察隅（墨脱）是近百年四川最强地震之一」的错误归属——察隅位于西藏林芝，非四川。
7. **为何分两份页面**：`index.html` 仅做跳转入口（轻量），完整交互逻辑与双地图在 `disaster_map_city.html`，避免单一 900KB+ 文件重复维护。

## 五、每年如何更新

本图**数据与代码分离，每年只需追加一页数据，无需改代码**。

### 方式 A：常规 git（本地有网络、能连 github.com 时）

1. 编辑 `disaster_data.json` 的 `events` 数组，按上方格式追加该年事件（`city` 用地级市短名）。
2. 提交并推送：

   ```bash
   git add disaster_data.json
   git commit -m "add 2027 disaster events"
   git push
   ```

3. GitHub Pages 会在数分钟内自动 rebuild，公开页面即反映最新数据。

### 修改代码 / 重新生成页面

如需调整生成逻辑，改 `gen_html_city.py` 等脚本后重跑：

```bash
python gen_city_map.py     # 生成 city_2026.svg / city_century.svg / city_data.json
python gen_html_city.py    # 生成 disaster_map_city.html
```

## 六、文件结构

| 文件 | 说明 |
|------|------|
| `index.html` | 入口跳转页，自动打开完整交互地图 |
| `disaster_map_city.html` | **成品页面**（自包含，含双地图 + 搜索 + 安全面板 + 城市全量排名 / 县级减产查询，~1.8MB） |
| `city_ranking.html` | **全国城市安全排名独立页**（可分享，默认显示全部城市，支持一线/新一线/全部切换、搜索、分页、导出 CSV，~72KB） |
| `gen_tier1_html.py` | 由 `city_data.json` 生成 `city_ranking.html` |
| `disaster_data.json` | **唯一数据源**：灾害事件（年月可检索）+ 元数据 |
| `city_alias.json` | 地名回退别名表（县/自治州/直辖市 → 地图节点），由 `build_alias.py` 生成，内嵌进成品页 |
| `build_alias.py` | 读取地图 SVG + 五级区划，生成 `city_alias.json` 并自检命中率 |
| `patch_disaster_types.py` | 补录偏少灾害类型（泥石流 / 雪灾）的可溯源历史事件，按 `(年,月,类型,省,市)` 去重 |
| `city_data.json` | 各城市分级与安全指数（由 `gen_city_map.py` 生成） |
| `city_2026.svg` / `city_century.svg` | 左 / 右两栏地图的 SVG 源（476 个地级节点，含自治州与直辖市市辖区） |
| `gen_map.py` | 省级地图 SVG 生成（早期版本，留存参考） |
| `gen_city_map.py` | 地级市地图 SVG 生成（合并边界 + 安全指数） |
| `gen_html.py` / `gen_html_city.py` | 由 SVG + 数据生成 HTML（城市版为成品） |
| `.gitignore` | 排除 `china_cities/`、`china_full.json`、`china_boundary.json`、`*.png`、`__pycache__/` |

## 七、合规与免责

- 底图依据自然资源部标准地图（DataV GeoAtlas）绘制，
  南海诸岛及断续线依国家标准示意呈现。
- 城市级安全指数仅衡量自然灾害暴露度，**不含经济、人口、基础设施与防灾能力**，
  **不作选址、投资、防灾规划等决策依据**。
- 数据来源：公开灾害年鉴、年度灾情通报及用户整理的年表，属科普示意，等级与统计为相对参考。
